# SOE Compliance Toolkit · 国有企业法务合规工具箱

面向国有企业法务合规工作的开源技能包，基于 Hermes / Claude Code / Cursor 等支持 Skill 机制的 Agent 运行时使用。

> 本套件所有内容均为独立原创编写，不包含任何第三方受版权保护的技能内容。法规引用均来源于公开发布的正式法律文本。

## 定位

国有企业法务合规工作具有高度标准化、强监管约束、强留痕要求三大特征。本套件将国资监管合规要求转化为可操作的 Agent 技能，覆盖：

- 合规管理体系审查（国资委令第46号）
- "三重一大"决策事项识别与程序审查
- 国有资产交易审查（国资委令第32号）
- 关联交易识别与管控
- 贸易真实性核验（四流合一、融资性贸易防范）
- 合同审查（采购 / 贸易 / 供应链金融）
- 招标采购合规
- 境外投资合规
- 数据合规（数据安全法 / 个人信息保护法 / 数据出境）
- 劳动用工合规
- 公文写作（GB/T 9704-2012）
- 诉讼文书写作（最高人民法院公开样式）
- 合规风险报告生成

## 快速开始

### 安装

将本仓库 `skills/` 目录下的技能子目录复制（或软链）到你的 Agent 技能目录：

- Hermes：`~/.hermes/profiles/<profile>/skills/`
- Claude Code：`~/.claude/skills/`
- Cursor / 其他：参照各平台技能安装方式

### 使用

安装后在对话中直接描述需求即可，例如：

- "对本公司《合规管理办法》开展 46 号令符合性体检"
- "这个采购项目是否属于'三重一大'决策事项？"
- "审查这份贸易合同是否存在融资性贸易特征"
- "起草一份向国资委的报告"

### 冷启动

首次使用建议先运行 `compliance-hub`（合规中枢）完成基础配置（企业性质、所属层级、业务板块等），以获得更精准的审查建议。

## 设计原则

1. **法规权威**：所有审查建议以现行有效法律法规为基准；法规条文无法确认时明确标注待核验，不臆造
2. **留痕合规**：审查过程保留完整记录，支持审计回溯
3. **不替代人工**：AI 输出为辅助审查意见，最终决策由合规管理部门和领导层作出
4. **敏感数据保护**：审查材料仅用于当次分析，不跨案件泄露；涉密材料提示线下处理
5. **平台无关**：技能通过能力槽调用外部服务（法律检索、工商信息等），未接入时自动降级并标注

## 工作台机制（P0）

| 机制 | 文件/技能 | 作用 |
|------|----------|------|
| 企业画像 | enterprise-onboarding + enterprise-profile.md | 按企业定制审查口径（性质/层级/监管环境/偏好） |
| 共享护栏 | Expert.md | 四级溯源（L1-L4）、通用铁律、能力槽协议、标准管线 |
| 法规核验闸门 | legal-verification | 正式文件输出前强制核验法规引用，防"AI 编法条" |
| 排版参数源 | format-spec.md | 字体/字号/行距/边距外部化，改格式不动代码 |
| 配置修改 | customize | 单项修改画像/排版配置，无需重跑访谈 |

**标准管线**：读取企业画像 → 收集材料 → 审查/起草(md) → 法规核验闸门 → 交付 md → 转 Word

## 统一排版输出

所有技能产出的正式 Word 文件统一使用套件脚本 `scripts/md2docx_gbt.py` 生成，保证格式固定一致：

| 文档类型 | 样式 | 命令 |
|---------|------|------|
| 公文 / 审查意见 / 核查意见 / 报告 | GB/T 9704-2012 公文格式 | `python3 scripts/md2docx_gbt.py in.md out.docx --type gongwen` |
| 诉讼文书 | 最高法诉讼文书样式 | `python3 scripts/md2docx_gbt.py in.md out.docx --type court` |

依赖：`pip install python-docx`

工作流：技能产出 Markdown → 用户确认 → 一键转 Word，全程格式统一。
