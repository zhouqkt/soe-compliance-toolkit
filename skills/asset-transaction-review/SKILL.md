# 国有资产交易审查（asset-transaction-review）

依据《企业国有资产交易监督管理办法》（国资委令第32号）对国有企业国有资产交易事项进行合规审查，覆盖产权转让、增资、资产转让三类主要交易。

## 法规框架

《企业国有资产交易监督管理办法》（国资委令第32号，2016年6月24日发布）是国有资产交易的核心依据，与《企业国有资产法》《企业国有资产评估管理暂行办法》（国资委令第12号）等配套适用。

## 三类交易审查要点

### 一、产权转让
- [ ] 是否履行内部决策程序（"三重一大"）
- [ ] 是否进行可行性研究和方案论证
- [ ] 是否履行审批程序（国资监管机构/国家出资企业）
- [ ] 是否进行清产核资、审计、评估
- [ ] 是否进场交易（产权交易机构公开进行）
- [ ] 转让底价是否以经核准/备案的评估结果为基础
- [ ] 信息披露是否达到规定期限（不少于20个工作日）
- [ ] 受让方资格条件是否合规设置
- [ ] 价款支付是否符合规定（一次性/分期，分期首付不低于30%）

### 二、增资扩股
- [ ] 是否履行内部决策和审批程序
- [ ] 是否进行审计、评估
- [ ] 是否进场公开征集投资方（特定情形除外）
- [ ] 投资方遴选标准是否合理
- [ ] 增资价格是否以评估结果为依据
- [ ] 是否避免利益输送（关联方参与增资的特殊审查）

### 三、资产转让
- [ ] 是否履行内部决策程序
- [ ] 是否评估（账面原值达到规定标准以上）
- [ ] 是否进场交易（转让底价100万元以上/账面原值100万元以上，标准以地方规定为准）
- [ ] 涉及房屋建筑物、土地使用权、知识产权等特殊资产的特别要求

## 强制进场交易的情形

以下情形原则上必须通过产权交易机构公开进行：
1. 国有及国有控股企业、国有实际控制企业产权转让
2. 国有及国有控股企业、国有实际控制企业增资（引入非公有资本）
3. 国有及国有控股企业、国有实际控制企业重大资产转让

## 例外情形审查（不需要进场交易的法定例外）

32号令规定的例外情形（如企业内部重组、同一国家出资企业内部协议转让等），须审查是否符合法定条件并履行相应程序。

## 工作流程

### Step 1: 收集交易信息
请用户提供：
1. 交易类型（产权转让/增资/资产转让）
2. 交易标的及金额
3. 交易对方（是否关联方）
4. 已履行程序（决策、审批、评估、进场情况）
5. 企业性质（国有独资/控股/参股）及层级

### Step 2: 合规审查
按上述要点逐项审查，判定：
- **合规**：程序完整
- **程序缺失**：缺某一步骤（如未评估、未进场）
- **需特别关注**：涉及关联交易、例外情形适用等

## 审查铁律

1. **评估是关键**：未经评估或评估未备案/核准的交易，是国资监管重点追责事项
2. **进场交易是原则**：应进场未进场的交易存在效力风险（可能被认定无效或可撤销）
3. **例外从严**：适用例外情形须有充分依据并留痕，防止规避进场交易
4. **关联交易叠加审查**：交易对方为关联方的，同时适用关联交易管控要求（联动 /related-party-review）
5. **地方差异**：地方国资委对交易金额标准、审批权限可能有细化规定，提示用户结合地方规定

## 输出前闸门（强制）

正式文件（审查意见书、核查意见、体检报告、制度文本、报告等）交付前，须过 /legal-verification 法规核验闸门（详见 Expert.md），核验全部法规、条文、监管文件引用；未核验的引用标注 `[L4-法规待核验]`，不得静默放行。

## Word 输出规范（统一）

所有正式 Word 文件统一使用套件脚本 `scripts/md2docx_gbt.py` 生成（GB/T 9704-2012 公文格式）：

```bash
python3 scripts/md2docx_gbt.py input.md output.docx --type gongwen
```

- 先输出 Markdown 供确认，确认后转 Word
- 脚本支持标记：`#`标题、`##`节标题、`|`表格、`>>`右对齐落款、`-`列表
- 文件命名：`{文种/事项}_{日期}.docx`
