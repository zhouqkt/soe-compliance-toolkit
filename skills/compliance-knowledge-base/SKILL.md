# 合规知识库（compliance-knowledge-base）

本地知识库三区管理，沉淀合规审查经验与法规资料，支持检索复用。

## 知识库结构（三区）

```
knowledge-base/
├── A区-法规库/          # 公域法规、监管文件（按主题归档）
│   ├── 46号令-合规管理/
│   ├── 32号令-国资交易/
│   ├── 贸易监管/
│   └── ...
├── B区-审查案例/        # 私域审查案例（脱敏后沉淀）
│   ├── 贸易真实性/
│   ├── 合同审查/
│   └── ...
└── C区-工作笔记/        # 私域工作笔记、经验总结
    └── ...
```

> 知识库根目录在 `enterprise-profile.md` 的 `KB.*` 能力槽配置；未配置时默认套件目录下 `knowledge-base/`。

## 工作流

### 检索模式

1. 用户提出检索需求（法规、案例、经验）
2. 按关键词在对应区域检索（本地 grep/read）
3. 输出相关条目及来源路径
4. 未命中时说明，并提示可接入外部知识库（Obsidian 等）

### 沉淀模式

审查/复盘完成后沉淀经验：

| 来源 | 沉淀到 | 内容 |
|------|--------|------|
| 审查结论 | B区-审查案例 | 事项类型、风险特征、处置建议（脱敏） |
| 复盘报告 | B区-审查案例 | 整改闭环经验、复发风险 |
| 新法规/监管动态 | A区-法规库 | 法规文件、要点摘录 |
| 工作心得 | C区-工作笔记 | 经验总结、注意事项 |

**沉淀格式**（案例类）：

```markdown
# {案例主题}

## 基本信息
- 类型：
- 日期：
- 结论：

## 风险特征
[列出识别出的风险特征]

## 处置经验
[有效的审查方法、处置建议]

## 教训/注意事项
[可复用的经验]

> 已脱敏：不包含企业名称、当事人、金额等敏感信息
```

## 铁律

1. **脱敏前置**：沉淀到知识库的内容必须脱敏（不含企业名称、当事人、真实金额）
2. **来源标注**：每条记录标注来源（事项编号、日期）
3. **不跨事项泄露**：检索输出仅限知识库内容，不涉及具体事项档案
4. **本地优先**：知识库存本地，未配置云端时不用云

## 外部能力（可选）

| 能力 | 用途 | 未接入时降级 |
|------|------|-------------|
