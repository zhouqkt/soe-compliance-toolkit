# 合规报告通用模板

> 本文件是 compliance-report 技能的模板单一权威源。各类合规报告按此结构组织。

```markdown
# XXX报告

## 一、基本情况
[背景、目的、依据、范围、方法]

## 二、工作开展情况
[组织实施、过程、数据]

## 三、发现的问题
[分条列明问题，注明严重程度：重大/较大/一般]

## 四、原因分析
[制度原因、执行原因、管理原因]

## 五、整改措施及建议
[分条列明，注明责任部门、完成时限]

## 六、结论
[总体评价、下一步工作安排]

附件：1.XXX
     2.XXX

XXX公司
2026年X月X日
```

## 报告类型适配

| 类型 | 结构调整 |
|------|---------|
| 合规风险报告 | 突出"风险识别+评估+应对"，问题部分改为风险矩阵 |
| 专项检查报告 | "发现的问题"部分分条列明问题+证据+依据 |
| 整改报告 | 对照问题逐项闭环：问题→措施→成效→佐证 |
| 自查报告 | 对照检查要求逐项：要求→自查结果→承诺 |
| 年度合规管理报告 | 工作+成效+问题+计划四段式 |

## 填写要求

1. 问题描述准确，附依据；数据不编造
2. 整改措施具体可落地（责任部门+时限）
3. 与前期审查结论口径一致
4. 法规引用输出前过 legal-verification 闸门
