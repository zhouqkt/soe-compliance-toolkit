# 合规复盘（compliance-review）

对合规审查发现的整改事项进行复盘评估，验证整改闭环、评估整改效果、识别复发风险，输出复盘报告。

## 适用场景

| 场景 | 复盘对象 | 输出 |
|------|---------|------|
| 整改复盘 | 审查发现问题的整改情况 | 整改复盘报告 |
| 专项复盘 | 专项检查（贸易/合同/招采）后的整改情况 | 专项复盘报告 |
| 年度复盘 | 年度合规工作总体情况 | 年度合规复盘报告 |

## 复盘流程

### Step 1: 确定复盘范围

- 从事项台账（compliance-matter-manager）提取待复盘的整改事项
- 或用户指定专项/年度复盘范围
- 确认复盘期间

### Step 2: 逐项核查整改情况

对每个整改事项核查：
1. 整改措施是否落实（对照整改计划逐项核验）
2. 整改是否到位（问题是否消除，而非表面整改）
3. 整改效果是否可持续（是否建立长效机制）
4. 是否有复发风险或新问题

判定：
- **已闭环**：整改措施落实、问题消除、机制建立
- **基本闭环**：整改基本落实，仍有细节待完善
- **未闭环**：整改未完成或未落实
- **复发**：问题再次出现

### Step 3: 输出复盘报告

```markdown
# 合规复盘报告

## 一、复盘范围
- 复盘类型：整改 / 专项 / 年度
- 复盘期间：
- 涉及事项数：

## 二、整改情况总览
| 状态 | 数量 | 占比 |
|------|------|------|
| 已闭环 | X | X% |
| 基本闭环 | X | X% |
| 未闭环 | X | X% |
| 复发 | X | X% |

## 三、逐项复盘结果
| 事项 | 整改措施 | 落实情况 | 判定 | 说明 |
|------|---------|---------|------|------|
| ... | ... | ... | 已闭环 | ... |

## 四、未闭环/复发事项分析
[逐项说明原因、障碍、下一步措施]

## 五、整体评价与建议
[合规管理水平评估、长效机制建议、下年度工作重点]

## 六、依据
[对照的监管要求、内部制度]

复盘人：
日期：
```

### Step 4: 台账更新

- 已闭环事项：更新台账状态（如适用）
- 未闭环/复发事项：更新整改计划、重新设定时限

## 复盘铁律

1. **以证据为准**：整改落实情况以佐证材料为准，不轻信口头汇报
2. **闭环判定从严**：机制未建立、问题可能复发的，不判定"已闭环"
3. **留痕**：复盘过程记录存档，支持审计回溯
4. **输出前过闸门**：复盘报告引用法规处须过 /legal-verification
5. **敏感保护**：复盘报告内部使用，对外仅输出汇总
