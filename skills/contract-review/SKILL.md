# 合同审查（contract-review）

对国有企业各类合同的合法合规性与商业风险进行审查，输出合同审查意见书。

## 适用合同类型

- 采购合同、销售合同、框架协议
- 贸易合同（大宗商品、供应链贸易）
- 供应链金融相关合同（保理、应收账款转让、仓单质押）
- 建设工程、服务合同
- 租赁、许可合同
- 投融资合同（借款、担保、投资协议）

## 通用审查框架

### 一、主体与资质
- [ ] 签约主体是否适格（法人资格、经营范围）
- [ ] 签约代表权限（授权委托书）
- [ ] 特殊资质（如建设工程、金融业务资质）

### 二、合同效力
- [ ] 意思表示是否真实
- [ ] 是否违反法律、行政法规强制性规定
- [ ] 是否损害国家利益、社会公共利益（国企合同特别关注）
- [ ] 是否涉及需要审批/登记的生效要件

### 三、标的与数量
- [ ] 标的物描述是否明确（品名、规格、型号、质量标准）
- [ ] 数量、计量单位是否清晰
- [ ] 质量标准及检验方法是否约定

### 四、价款与支付
- [ ] 价格条款是否明确（含税/不含税、调价机制）
- [ ] 支付方式、支付节点是否清晰
- [ ] 定金、预付款比例是否合理
- [ ] 发票开具约定（发票类型、税率、开票时点）

### 五、履行与交付
- [ ] 交付方式、时间、地点
- [ ] 运输、保险责任划分
- [ ] 验收标准与程序
- [ ] 风险转移时点

### 六、违约责任
- [ ] 违约情形定义是否清晰
- [ ] 违约金标准是否合理（不超过实际损失30%的参考标准）
- [ ] 赔偿范围是否明确
- [ ] 责任限制条款是否合理

### 七、争议解决
- [ ] 管辖约定（法院/仲裁）是否明确有效
- [ ] 适用法律
- [ ] 送达条款是否有效

### 八、国企特别关注
- [ ] 是否履行"三重一大"决策程序（重大合同）
- [ ] 是否经过法律合规审查
- [ ] 是否涉及国有资产交易（联动32号令审查）
- [ ] 是否涉及关联交易（联动关联交易审查）
- [ ] 是否涉及融资性贸易风险（联动贸易真实性审查）
- [ ] 付款安排是否符合"先收款后付款"等贸易合规要求

## 工作流程

### Step 1: 接收合同文本
请用户提供：
1. 合同文本（或关键条款）
2. 合同背景（交易对手、交易目的、已履行的内部程序）
3. 审查重点（如用户有关注的风险点）

### Step 2: 逐条审查
按上述框架逐条审查，输出意见：

### Step 3: 输出审查意见书

```markdown
# 合同审查意见书

## 一、合同概况
- 合同名称：
- 合同编号：
- 签约主体：
- 合同金额：
- 审查日期：

## 二、审查结论
- 总体评价：风险可控 / 存在较大风险 / 风险高（建议缓签）
- 主要风险等级：高风险 X 项 / 中风险 X 项 / 低风险 X 项

## 三、逐条审查意见
| 序号 | 条款/事项 | 原文要点 | 风险等级 | 审查意见 | 修改建议 |
|------|----------|---------|---------|---------|---------|
| 1 | ... | ... | 高/中/低 | ... | ... |

## 四、重点风险提示
[列出高风险事项及原因]

## 五、签署建议
- 建议：签署 / 修改后签署 / 暂缓签署
- 前提条件：[需落实的事项]

审查人：
日期：
```

## 审查铁律

1. **条款原文为准**：以合同文本原文为依据，不臆测未写明的条款
2. **风险分级**：每条意见标注高/中/低风险等级
3. **修改建议可落地**：给出具体修改措辞建议（"建议修改为：……"）
4. **国企合规叠加**：贸易类合同联动审查融资性贸易特征；涉关联、涉国资交易须提示联动审查
5. **不替代专业意见**：输出为辅助审查意见，重大合同建议同时由专业律师复核
