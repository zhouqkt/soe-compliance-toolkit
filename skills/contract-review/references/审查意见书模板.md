# 合同审查意见书模板

> 本文件是 contract-review 技能的模板单一权威源。合同审查完成后按此结构输出正式意见书。

```markdown
# 合同审查意见书

## 一、合同概况
- 合同名称：
- 合同编号：
- 签约主体：
- 合同金额：
- 审查日期：

## 二、审查结论
- 总体评价：风险可控 / 存在较大风险 / 风险高（建议缓签）
- 主要风险：高风险 X 项 / 中风险 X 项 / 低风险 X 项

## 三、逐条审查意见

| 序号 | 条款/事项 | 原文要点 | 风险等级 | 审查意见 | 修改建议 |
|------|----------|---------|---------|---------|---------|
| 1 | ... | ... | 高/中/低 | ... | ... |

## 四、重点风险提示
[列出高风险事项及原因]

## 五、签署建议
- 建议：签署 / 修改后签署 / 暂缓签署
- 前提条件：[需落实的事项]

审查人：
日期：
```

## 填写要求

1. 以合同原文为依据，不臆测未写明的条款
2. 每条意见标注高/中/低风险等级，修改建议给出具体措辞
3. 贸易类合同联动核查融资性贸易特征（见 trade-authenticity-check）
4. 涉及关联交易、国资交易提示联动审查
5. 法规引用输出前过 legal-verification 闸门
