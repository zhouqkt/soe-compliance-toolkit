# 配置修改（customize）

对套件配置进行单项快速修改，无需重跑完整访谈。

## 适用配置项

| 配置 | 位置 | 可修改内容 |
|------|------|-----------|
| 企业画像 | enterprise-profile.md | 企业基本盘、监管环境、制度流程、审查偏好、能力后端 |
| 排版参数 | format-spec.md | 字体、字号、行距、页边距、样式 |
| 事项配置 | matters/{slug}/matter.md | 事项级口径（P1 启用） |

## 工作流程

### Step 1: 明确修改目标
确认用户要改哪类配置、哪个字段。

### Step 2: 读取当前配置
读取目标文件对应字段的当前值，向用户确认修改前后对比。

### Step 3: 修改并回显
1. 修改对应字段（保留文件其他内容不变）
2. 回显修改后的字段值供确认
3. 提示修改生效范围（影响哪些技能）

### 示例

```
用户：把风险偏好改成"审慎"
→ 读取 enterprise-profile.md → risk_calibration: 稳健
→ 修改为: risk_calibration: 审慎
→ 回显: ✅ 已修改。影响：所有审查技能的风险判定倾向。
```

## 铁律

1. 只改用户指定的字段，不连带修改其他内容
2. 修改前备份原值（记录修改历史，支持回滚）
3. 排版参数修改后提示：脚本 `scripts/md2docx_gbt.py` 下次生成时自动生效
4. 涉及企业敏感信息修改时提醒：仅存本地，不外发
