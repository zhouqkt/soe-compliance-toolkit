# 排版校验（document-formatting）

正式文件转 Word 前的格式合规校验闸门。检查 Markdown 文档结构是否满足 `format-spec.md` 排版规范，校验通过后调用统一生成器输出 Word。

## 触发条件

- 正式文件（审查意见书、核查意见、体检报告、制度文本、公文、诉讼文书）转 Word 前
- 用户要求"检查格式""排版校验"

## 校验项（V1-V8）

| 编号 | 校验项 | 规则 |
|------|--------|------|
| V1 | 标题 | 仅 1 个一级标题（#），居中；标题文字不折行 |
| V2 | 节标题层级 | ## / ### 层级连续，不跳级 |
| V3 | 表格结构 | 表格首行为表头；列数一致；无空表 |
| V4 | 落款 | 落款用 `>> ` 标记右对齐（核查人、日期） |
| V5 | 列表 | 列表项用 `- ` 标记，不混用其他符号 |
| V6 | 非法标记 | 无 HTML 标签（`<div>`、`&nbsp;` 等） |
| V7 | 待核验标注 | 涉及法规引用的正式文件含 `[L4-待核验]` 标注时提示人工确认 |
| V8 | 文档类型 | 按文档类型（gongwen/court）核对样式要求 |

## 工作流程

### Step 1: 接收待校验文档
接收 Markdown 文档（或待转 Word 的文件路径）。

### Step 2: 逐项校验
按 V1-V8 逐项检查，输出结果：

```markdown
# 排版校验结果

| 编号 | 校验项 | 结果 | 问题说明 |
|------|--------|------|---------|
| V1 | 标题 | 通过/不通过 | ... |
| V2 | 节标题层级 | ... | ... |
| V3 | 表格结构 | ... | ... |
| V4 | 落款 | ... | ... |
| V5 | 列表 | ... | ... |
| V6 | 非法标记 | ... | ... |
| V7 | 待核验标注 | ... | ... |
| V8 | 文档类型 | ... | ... |

## 结论
- 通过 → 可转 Word
- 不通过 → 列出需修正项，修正后复检
```

### Step 3: 生成 Word
校验通过后，调用 `scripts/md2docx_gbt.py` 按文档类型生成：
- 公文/审查/报告：`--type gongwen`
- 诉讼文书：`--type court`

## 铁律

1. **先校验后生成**：格式问题在 md 阶段修正，不生成后再返工
2. **不静默跳过**：V6 非法标记发现即退回修正
3. **排版参数以 format-spec.md 为准**：脚本与校验器均读外部参数源
4. **诉讼文书特殊要求**：标题不加粗、正文四号宋体、行距固定25磅（court 样式）

## 后续衔接

- 校验不通过 → 修正 md 后复检
- 校验通过 → 转 Word 交付
