# 文档解析（document-parse）

将上传的 PDF、Word、扫描件、图片等文件解析为结构化 Markdown，作为审查流程的输入前门。

## 触发条件

- 用户上传文件（PDF 合同、扫描件、制度文件、单据等）要求审查
- 用户要求"解析这个文件""提取内容"
- 审查技能收到文件输入时自动调用

## 解析流程

### Step 1: 识别文件类型

| 文件类型 | 处理方式 |
|---------|---------|
| PDF（文本型） | 提取文本层 |
| PDF（扫描型） | OCR 识别 |
| Word (.docx) | 直接提取文本（python-docx） |
| 图片 (png/jpg) | OCR 识别 |
| Excel | 提取表格数据 |

### Step 2: 解析为结构化 Markdown

- 保留标题层级、段落、表格结构
- 长文档分段输出，标注页码/段落来源
- 解析结果供审查技能直接使用

### Step 3: 输出

```markdown
# {文件名} 解析结果

> 来源：{文件路径} | 解析方式：{文本提取/OCR} | 解析时间：{时间}

## 文档结构
[按文档实际结构输出，保留标题、段落、表格]

## 解析说明
- 识别完整性：
- 不确定/模糊内容标注：[OCR不确定] [模糊]
```

## 铁律

1. **不臆造内容**：OCR 或提取失败的内容标注不确定，绝不编造文档内容
2. **保留来源**：解析结果标注来源文件，支持回溯核对
3. **敏感处理**：涉密文件提示线下处理，解析结果不扩散
4. **长文档分块**：超长文档分段解析，避免遗漏
