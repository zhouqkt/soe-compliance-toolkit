# 企业画像访谈（enterprise-onboarding）

通过简短访谈收集企业基本信息、监管环境、审查偏好，写入 `enterprise-profile.md`，使全套件按企业实际情况定制审查口径。

## 触发条件

- 首次使用套件（`enterprise-profile.md` 不存在或关键字段为空）
- 用户说"重新配置""初始化""企业画像"
- 企业信息发生变化（层级调整、业务板块变化、监管要求更新）

## 核心原则

1. **不重复问已知信息**：先读 `enterprise-profile.md`，只补缺口
2. **每轮最多 2-3 个问题**：等待回答后再继续
3. **可跳过**：用户说"跳过"则保留占位，后续通过 /customize 补充
4. **快速完成**：全程 5 分钟内可走完

## 访谈流程

### Phase 1：企业基本盘

确认/补充：
- 企业全称、性质（央企 / 地方国企 / 金融国企 / 事业单位）
- 层级（一级 / 二级 / 三级 / 上市公司）
- 主要行业、业务板块
- 上级单位（如有）

### Phase 2：监管环境

- 主管国资监管机构（省/市国资委、集团总部）
- 适用监管文件（默认：《中央企业合规管理办法》国资委令第46号）
- 地方/行业特殊规定

### Phase 3：制度与流程

- 现行制度清单（合规管理办法、合同管理制度、贸易管理制度等）
- 金额阈值（三重一大、招标采购、国资交易等）
- 主要审批流程

### Phase 4：审查偏好

- 风险偏好（稳健 / 审慎 / 进取）
- 报告风格（正式 / 简洁 / 详实）
- 审查口径（从严 / 中性 / 务实）
- 参考样本（如有）

### Phase 5：能力后端与排版

- 外部能力后端（法律检索、工商信息、知识库是否配置）
- 默认 Word 样式（gongwen 公文 / court 法院文书）

## 输出

访谈完成后写入 `enterprise-profile.md`（套件根目录），并提示：

```
✅ 企业画像已配置完成。已记录：企业性质、监管环境、审查偏好等。
后续所有合规审查技能将按本企业口径执行。
如需修改单项配置，运行 /customize。
```

## 铁律

1. 不编造企业信息：用户未确认的信息留空或标占位，不自行推断填写
2. 敏感信息不入公开文档：企业画像含内部信息，仅存本地，不随任何产出外发
3. 访谈结果可迭代：任何时候可重跑或单项修改
