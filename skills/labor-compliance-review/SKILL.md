# 劳动用工合规审查（labor-compliance-review）

对国有企业劳动用工管理开展合规审查，覆盖招聘入职、劳动合同、工时休假、薪酬社保、劳动保护、规章制度、解除终止、争议处理全流程。

## 法规框架

- 《中华人民共和国劳动合同法》（2012年修正）
- 《中华人民共和国劳动合同法实施条例》
- 《中华人民共和国社会保险法》
- 《工伤保险条例》
- 《职工带薪年休假条例》《企业职工带薪年休假实施办法》
- 《住房公积金管理条例》
- 《劳动争议调解仲裁法》
- 地方劳动法规及标准（地方国企适用）

## 审查维度

### 一、招聘与入职
- [ ] 招聘信息是否合规（无就业歧视）
- [ ] 入职审查是否合规（背景调查、学历核验，不非法收集个人信息）
- [ ] 是否依法签订书面劳动合同（入职1个月内）
- [ ] 试用期约定是否合法（期限、次数、工资不低于80%）

### 二、劳动合同管理
- [ ] 合同类型是否合规（固定期限/无固定期限/以完成一定工作任务为期限）
- [ ] 应签无固定期限情形是否依法签订（连续工作满10年、连续订立两次固定期限合同等）
- [ ] 合同内容是否完备（必备条款）
- [ ] 合同变更是否协商一致并书面确认
- [ ] 劳务派遣用工是否合规（临时性/辅助性/替代性、比例不超过10%）

### 三、工时与休假
- [ ] 工时制度是否合规（标准工时8小时/40小时；综合计算工时、不定时是否经审批）
- [ ] 加班管理是否合规（时长限制、加班费支付标准：150%/200%/300%）
- [ ] 带薪年休假是否落实（未休年假按300%支付）
- [ ] 法定节假日、婚丧假、产假、陪产假是否依法保障

### 四、薪酬与社保
- [ ] 工资支付是否按时足额（不得克扣、拖欠）
- [ ] 工资构成是否合规（不得低于当地最低工资标准）
- [ ] 社会保险是否依法缴纳（养老、医疗、失业、工伤、生育五险）
- [ ] 住房公积金是否依法缴存
- [ ] 高温补贴、特殊岗位津贴是否落实

### 五、劳动保护与安全生产
- [ ] 劳动安全卫生条件是否达标
- [ ] 职业健康检查是否开展
- [ ] 工伤预防与申报是否合规
- [ ] 女职工特殊保护是否落实（三期保护）

### 六、规章制度
- [ ] 规章制度是否履行民主程序（经职工代表大会或全体职工讨论）
- [ ] 规章制度是否向劳动者公示或告知
- [ ] 规章制度内容是否合法合理
- [ ] 奖惩制度是否明确（可作为解除依据的严重违纪情形）

### 七、解除与终止
- [ ] 协商解除是否支付经济补偿
- [ ] 过失性解除是否依法定情形（严重违纪、严重失职、兼职、欺诈胁迫等）
- [ ] 无过失性解除是否履行预告程序（提前30日通知或代通知金）
- [ ] 经济性裁员是否履行法定程序（提前30日向工会说明、报告劳动行政部门）
- [ ] 不得解除情形是否遵守（三期女职工、医疗期、工伤等）
- [ ] 经济补偿金计算是否合规（N、N+1标准；月工资3倍封顶）
- [ ] 离职手续是否完备（解除证明、档案、社保转移）

### 八、劳动争议
- [ ] 劳动争议调解机制是否建立
- [ ] 仲裁应诉是否及时（15日答辩期）
- [ ] 是否建立劳动用工风险预警

## 工作流程

### Step 1: 收集信息
请用户提供：
1. 用工规模与类型（正式工、劳务派遣、外包）
2. 审查重点（合同管理/工时社保/解除合规等）
3. 相关材料（劳动合同样本、规章制度、工资表、社保缴纳情况、涉争议情况）

### Step 2: 合规审查
按上述维度逐项检查，判定：合规 / 部分合规 / 不合规 / 不适用

## 审查铁律

1. **未签合同风险最高**：入职超1个月未签书面劳动合同，需支付双倍工资（最多11个月），属高发争议点
2. **违法解除风险大**：违法解除须支付赔偿金（2N），审查解除依据和程序
3. **社保是硬义务**：社保未缴、欠缴、基数不足均属违规，且不能以现金补偿替代
4. **制度程序要双全**：规章制度须民主程序+公示告知，否则不能作为解除依据
5. **地方标准差异**：最低工资、社保基数、补贴标准等以当地规定为准，提示用户核实
6. **不涉及个别人隐私**：审查中涉及的员工个人信息不输出到对话

## Word 输出规范（统一）

所有正式 Word 文件统一使用套件脚本 `scripts/md2docx_gbt.py` 生成（GB/T 9704-2012 公文格式）：

```bash
python3 scripts/md2docx_gbt.py input.md output.docx --type gongwen
```

- 先输出 Markdown 供确认，确认后转 Word
- 脚本支持标记：`#`标题、`##`节标题、`|`表格、`>>`右对齐落款、`-`列表
- 文件命名：`{文种/事项}_{日期}.docx`
