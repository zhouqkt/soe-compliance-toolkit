# 诉讼文书写作（litigation-document-writing）

依据最高人民法院公开的诉讼文书样式，起草国有企业涉诉法律文书。本技能仅使用公开发布的法院文书样式规范，所有模板为独立编写。

## 适用文书

- 民事起诉状（一审）
- 民事答辩状
- 民事上诉状（二审）
- 再审申请书
- 代理词（庭前/庭后）
- 证据清单/证据目录
- 保全申请书
- 管辖权异议申请书

## 通用规范（基于最高法公开样式）

### 页面与字体
- 纸张：A4
- 标题：宋体二号居中（不加粗）
- 正文：宋体四号，首行缩进2字符
- 行距：固定值25磅左右
- 落款：右对齐；日期格式"2026年X月X日"

### 结构要素
1. 文书标题（居中）
2. 当事人信息（原告/被告/第三人；法人与自然人格式不同）
3. 诉讼请求（分条列明）
4. 事实与理由（时间线叙述 + 法律论证）
5. 此致 + 法院名称
6. 具状人/盖章
7. 日期
8. 附项（副本份数、证据材料清单）

## 各文书要点

### 民事起诉状
- 当事人：原告（我方）、被告，法人需列法定代表人
- 诉讼请求：明确、具体、可执行（金额精确到元）
- 事实与理由：时间线 + 三段论（法律依据→事实→结论）
- 管辖法院正确（级别管辖、地域管辖、专属管辖）

### 民事答辩状
- 针对原告诉讼请求逐项回应
- 承认/否认/抗辩分类明确
- 事实与理由：反驳原告主张 + 己方事实与依据

### 上诉状
- 上诉请求：撤销/变更一审判决的具体表述
- 上诉理由：指出原判错误（认定事实错误/适用法律错误/程序违法）
- 注意上诉期限（判决书送达之日起15日内）

### 再审申请书
- 必须援引法定再审事由（《民事诉讼法》规定情形）
- 注意申请期限（判决生效后6个月内）
- 致送上一级法院或原审法院

### 代理词
- 庭审重点：争议焦点、证据质证意见、法律适用
- 庭后补充：针对庭审情况补充论证

## 工作流程

### Step 1: 收集案件材料
请用户提供：
1. 案件基本情况（案由、当事人、合同/纠纷背景）
2. 诉讼请求（或应诉答辩要点）
3. 证据材料清单
4. 程序阶段（一审/二审/再审）

### Step 2: 主体信息核实
- 企业主体：核实企业全称、统一社会信用代码、住所地、法定代表人
- 自然人主体：姓名、住址等
- **缺失信息保留"[待补充]"占位，严禁编造**

### Step 3: 起草文书
按对应文书类型规范起草，事实以用户提供材料为准，法律论证明确标注依据（法条、案例），无法确认的标注待核验。

### Step 4: 输出
- 默认输出 Markdown 版供确认
- 确认后生成 .docx（按法院文书样式排版）

```markdown
# 民事起诉状

原告：[名称]，统一社会信用代码：[代码]，住所地：[地址]。
法定代表人：[姓名]，职务：[职务]。

被告：[名称]，住所地：[地址]。

## 诉讼请求
1. [请求事项一]
2. [请求事项二]
3. 本案诉讼费用由被告承担。

## 事实与理由
[按时间顺序陈述案件事实]

[法律适用论证：依据《XXX法》第X条……]

综上所述，原告的诉讼请求事实清楚、证据充分、于法有据，恳请贵院依法支持。

此致
[法院名称]

具状人：[原告名称]（盖章）
2026年X月X日

附：1. 本状副本X份
    2. 证据材料X份
```

## 写作铁律

1. **事实真实**：以用户提供的真实材料为据，不臆造事实、不编造证据
2. **主体信息不编造**：缺失信息用"[待补充]"占位
3. **法条待核验**：法律条文引用须经核验，未核验标注"[待核验]"
4. **文书样式规范**：按最高法公开样式排版
5. **非法律意见**：本技能产出为文书草稿，正式提交前须经执业律师复核

## 输出前闸门（强制）

正式文件（审查意见书、核查意见、体检报告、制度文本、报告等）交付前，须过 /legal-verification 法规核验闸门（详见 Expert.md），核验全部法规、条文、监管文件引用；未核验的引用标注 `[L4-法规待核验]`，不得静默放行。

## Word 输出规范（统一）

所有诉讼文书 Word 文件统一使用套件脚本 `scripts/md2docx_gbt.py` 生成（最高法诉讼文书样式）：

```bash
python3 scripts/md2docx_gbt.py input.md output.docx --type court
```

- 先输出 Markdown 供确认，确认后转 Word
- 标题宋体二号居中不加粗；正文宋体四号首行缩进2字符；行距固定25磅
- 禁止在文中使用 HTML 标签（排版由脚本控制）
