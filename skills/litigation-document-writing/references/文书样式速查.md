# 诉讼文书样式速查（最高法公开样式）

> 本文件是 litigation-document-writing 技能的样式速查。起草诉讼文书时按此规范执行。
> 本速查基于最高人民法院公开发布的诉讼文书样式编写，独立整理，不复制任何第三方技能内容。

## 版式参数

| 项目 | 参数 |
|------|------|
| 页面 | A4 |
| 上下边距 | 2.54cm |
| 左右边距 | 3.17cm |
| 行距 | 固定值 25 磅 |

## 字体字号

| 元素 | 字体 | 字号 |
|------|------|------|
| 文书标题 | 宋体 | 二号（22pt），居中，不加粗 |
| 正文 | 宋体 | 四号（14pt），首行缩进2字符 |
| 落款 | 宋体 | 四号，右对齐 |

## 通用结构

1. **标题**：居中（如"民事起诉状"）
2. **当事人信息**：原告/被告/第三人；法人列法定代表人
3. **诉讼请求**：分条列明，明确具体
4. **事实与理由**：时间线叙述 + 法律论证（三段论）
5. **此致**：首行缩进2字符
6. **法院名称**：顶格左对齐
7. **具状人/盖章**：右对齐
8. **日期**：右对齐（2026年X月X日）
9. **附项**：副本份数、证据材料清单

## 各文书要点

| 文书 | 要点 |
|------|------|
| 起诉状 | 请求明确；管辖正确；事实时间线 |
| 答辩状 | 针对请求逐项回应；承认/否认/抗辩分类 |
| 上诉状 | 撤销/变更原判；点原判错误；15日上诉期 |
| 再审申请书 | 援引法定再审事由；6个月申请期 |
| 代理词 | 争议焦点+质证意见+法律适用 |

## 铁律

1. 事实以用户材料为准，不臆造、不编证据
2. 主体信息缺失用"[待补充]"占位，严禁编造
3. 法条引用须核验（过 legal-verification 闸门），未核验标注 [L4-待核验]
4. 禁止在文中使用 HTML 标签（排版由脚本控制）
5. 草稿正式提交前须经执业律师复核

## 生成方式

正式 Word 统一用 `scripts/md2docx_gbt.py --type court` 生成。
