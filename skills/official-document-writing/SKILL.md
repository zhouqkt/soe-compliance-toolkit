# 公文写作（official-document-writing）

依据《党政机关公文处理工作条例》和《党政机关公文格式》（GB/T 9704-2012），起草国有企业各类公文，输出符合格式要求的正式文档。

## 适用文种

| 文种 | 用途 | 适用场景 |
|------|------|---------|
| 请示 | 请求上级指示、批准 | 事项需上级审批 |
| 报告 | 向上级汇报工作、反映情况 | 汇报工作、回复询问 |
| 函 | 不相隶属机关商洽工作 | 与外部单位沟通 |
| 通知 | 发布、传达要求 | 部署工作、告知事项 |
| 纪要 | 记载会议情况和议定事项 | 会议记录 |
| 决定 | 重大事项安排 | 奖惩、机构调整 |
| 批复 | 答复请示事项 | 回复下级请示 |
| 意见 | 对重要问题提出见解和处理办法 | 建议性文件 |

## 公文格式规范（GB/T 9704-2012）

### 版式
- 页面：A4
- 页边距：上 3.7cm，下 3.5cm，左 2.8cm，右 2.6cm
- 行距：固定值 28 磅（可微调）
- 每面 22 行，每行 28 字（文档网格）

### 字体字号
| 元素 | 字体 | 字号 |
|------|------|------|
| 标题 | 方正小标宋简体 | 二号（22pt） |
| 正文 | 仿宋_GB2312 | 三号（16pt） |
| 一级标题 | 黑体 | 三号 |
| 二级标题 | 楷体_GB2312 | 三号 |
| 三级标题 | 仿宋_GB2312 | 三号 |
| 数字/英文 | Times New Roman | 随正文 |

### 结构要素
- 标题：发文机关+事由+文种
- 主送机关：顶格
- 正文：开头（缘由）→ 主体（事项）→ 结尾（结语）
- 附件说明：正文下空一行
- 发文机关署名：正文后右空
- 成文日期：署名下方右空四字（阿拉伯数字）
- 页码："-1-"格式

## 各文种写作要点

### 请示
- 一文一事
- 主送一个上级机关
- 理由充分、依据明确
- 结语："妥否，请批示"

### 报告
- 不得夹带请示事项
- 陈述性：做了什么、怎么做的、结果如何
- 结语："特此报告"

### 函
- 语气平等、商洽性
- 事项明确
- 结语："妥否，请函复"

### 通知
- 目的明确、要求具体
- 层次清晰（开头缘由、主体事项、结尾要求）

### 会议纪要
- 会议基本情况（时间、地点、主持人、参会人）
- 议定事项（分条列明）
- 执行要求（责任部门、时限）

## 工作流程

### Step 1: 明确写作需求
请用户提供：
1. 文种（请示/报告/函/通知/纪要等）
2. 发文机关、主送机关
3. 事由和主要内容
4. 相关背景材料
5. 是否红头（正式公文）或普通函件（如公司对外回函）

### Step 2: 起草初稿
按文种规范起草，结构完整、用语规范。国企公文注意：
- 引用政策文件要准确（文件名、文号）
- 涉及"三重一大"事项说明决策程序
- 涉及数据要准确

### Step 3: 格式排版与输出
- 正文输出 Markdown 版供确认
- 确认后生成 .docx（按 GB/T 9704-2012 排版）
- 用户公司惯例：对外函件可不带红头、发文字号，标题单行不折行，落款右对齐+日期右空4字

### Step 4: 输出示例（请示）

```markdown
关于XXX事项的请示

集团公司：

[缘由：依据什么、为什么需要请示]

[主体：请示的具体事项、方案、请求批准的内容]

妥否，请批示。

附件：1.XXX
      2.XXX

XXX公司
2026年X月X日

（联系人：XXX，电话：XXX）
```

## 写作铁律

1. **文种正确**：请示与报告不可混用；函与请示不可混用
2. **一文一事**（请示）
3. **用语规范**：使用法定公文用语，不用口语化表达
4. **数据准确**：涉及数据、金额、日期必须准确，不确定的不编造
5. **引用规范**：引用政策文件写明名称+文号，并核验现行有效性
6. **不虚构事实**：公文内容基于用户提供的真实材料，缺失信息明确询问
