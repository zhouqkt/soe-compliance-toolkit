# 公文格式速查（GB/T 9704-2012）

> 本文件是 official-document-writing 技能的格式速查。起草公文时按此规范执行。

## 版式参数

| 项目 | 参数 |
|------|------|
| 页面 | A4 |
| 上边距 | 3.7cm |
| 下边距 | 3.5cm |
| 左边距 | 2.8cm |
| 右边距 | 2.6cm |
| 行距 | 固定值 28 磅（可微调） |
| 每面 | 22行，每行28字（文档网格） |

## 字体字号

| 元素 | 字体 | 字号 |
|------|------|------|
| 标题 | 方正小标宋简体 | 二号（22pt） |
| 正文 | 仿宋_GB2312 | 三号（16pt） |
| 一级标题（一、） | 黑体 | 三号 |
| 二级标题（（一）） | 楷体_GB2312 | 三号 |
| 三级标题（1.） | 仿宋_GB2312 | 三号 |
| 数字/英文 | Times New Roman | 随正文 |

## 结构要素

1. **标题**：发文机关+事由+文种（如《XX公司关于开展XX检查的通知》）
2. **主送机关**：顶格，回行时仍顶格，末尾加冒号
3. **正文**：开头（缘由）→ 主体（事项）→ 结尾（结语）
4. **附件说明**：正文下空一行，左空二字标注"附件："
5. **发文机关署名**：正文（含附件）后右空二字
6. **成文日期**：署名下方右空四字（阿拉伯数字）
7. **页码**："-1-"样式，单页居右空一字，双页居左空一字

## 各文种结语速查

| 文种 | 常用结语 |
|------|---------|
| 请示 | "妥否，请批示。" |
| 报告 | "特此报告。" |
| 函 | "妥否，请函复。" |
| 通知 | "特此通知。" |
| 批复 | "此复。" |

## 写作铁律

1. 一文一事（请示）；请示不得多头主送
2. 报告不得夹带请示事项
3. 引用文件写明名称+文号，核验现行有效
4. 数据准确，不确定不编造
5. 不虚构事实，缺失信息询问用户
6. 法规引用输出前过 legal-verification 闸门

## 生成方式

正式 Word 统一用 `scripts/md2docx_gbt.py --type gongwen` 生成。
