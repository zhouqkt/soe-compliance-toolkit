# 境外投资合规审查（overseas-investment-review）

对国有企业境外投资项目开展合规审查，覆盖投资前期论证、备案/核准程序、决策审批、风险评估、投后管理全流程。

## 法规框架

- 《企业境外投资管理办法》（国家发展改革委令第11号，2017年）—— 发改委备案/核准
- 《境外投资管理办法》（商务部令2014年第3号）—— 商务部门备案
- 《中央企业境外投资监督管理办法》（国资委令第35号）—— 央企境外投资监管
- 《企业境外投资管理办法》配套：境外投资敏感行业目录
- 外汇管理规定（国家外汇管理局关于境内居民通过特殊目的公司境外投融资及返程投资外汇管理有关问题的通知等）
- 地方国资委境外投资监管规定（地方国企适用）

## 审查要点

### 一、投资方向与合规底线
- [ ] 是否涉及禁止类项目（危害国家安全、违反国际义务等）
- [ ] 是否涉及限制类/敏感行业（需核准）
- [ ] 是否涉及敏感国家和地区
- [ ] 是否属于非主业境外投资（央企非主业投资管控）

### 二、前期论证
- [ ] 是否开展可行性研究（市场、技术、财务、法律）
- [ ] 是否开展尽职调查（目标公司、交易对手、当地法律环境）
- [ ] 是否进行风险评估（政治风险、法律风险、汇率风险、合规风险）
- [ ] 是否出具风险评估报告

### 三、备案/核准程序
- [ ] 是否按规定履行发改委备案/核准（敏感项目核准，一般项目备案）
- [ ] 是否按规定履行商务部门备案
- [ ] 是否按规定办理外汇登记/备案（ODI 外汇登记）
- [ ] 备案信息是否真实完整

### 四、决策审批程序
- [ ] 是否履行"三重一大"决策程序
- [ ] 是否经党委（党组）前置研究
- [ ] 是否报上级集团/国资监管机构审批（按权限）
- [ ] 是否履行法律合规审查

### 五、投后管理
- [ ] 是否建立境外投资投后管理制度
- [ ] 是否定期报告项目运营情况
- [ ] 重大事项（增资、退出、重大损失）是否及时报告
- [ ] 是否存在国有资产流失风险

### 六、特别关注
- [ ] 是否涉及通过境外特殊目的公司（SPV）返程投资
- [ ] 是否存在规避监管结构（多层嵌套、代持）
- [ ] 是否违反外汇管理规定
- [ ] 是否涉及敏感地区制裁风险（美国 OFAC、欧盟制裁等）

## 工作流程

### Step 1: 收集项目信息
请用户提供：
1. 投资主体（央企/地方国企/层级）
2. 投资标的（国家/地区、行业、金额、持股比例）
3. 项目阶段（意向/论证/备案/实施/投后）
4. 已履行程序（决策、备案、核准情况）
5. 相关文件（可研报告、尽调报告、风险评估、备案文件）

### Step 2: 合规审查
按上述要点逐项审查，判定：合规 / 程序缺失 / 存在重大风险

## 审查铁律

1. **备案/核准是前置**：未履行发改委/商务部门备案核准程序的境外投资，属于违规操作
2. **敏感项目从严**：敏感国家和地区、敏感行业的项目须核准，不得以备案规避
3. **非主业管控**：央企境外投资聚焦主业，非主业投资须严格审批
4. **外汇合规**：未办理 ODI 外汇登记的资金出境存在违规风险
5. **风险揭示**：政治风险、制裁风险必须如实揭示，不弱化风险表述
6. **地方差异**：地方国企适用当地国资委境外投资监管规定，提示用户核实
