# 招标采购合规审查（procurement-review）

对国有企业招标采购活动进行全流程合规审查，覆盖采购方式选择、招标程序、评标定标、合同签订各环节。

## 法规框架

- 《中华人民共和国招标投标法》
- 《中华人民共和国招标投标法实施条例》
- 《必须招标的工程项目规定》（国家发改委令第16号）
- 《中华人民共和国政府采购法》（涉及政府采购活动时）
- 地方国资采购监管规定（如阳光采购平台要求）

## 审查要点

### 一、采购方式选择
- [ ] 是否依法确定必须招标的范围（工程建设项目达到标准必须招标）
- [ ] 非必须招标项目是否按企业制度选择采购方式（公开招标/邀请招标/竞争性谈判/竞争性磋商/询价/单一来源）
- [ ] 是否存在规避招标情形（化整为零、肢解项目、以时间紧迫为由）
- [ ] 单一来源采购是否符合法定情形

### 二、招标程序
- [ ] 招标公告是否依法发布（公告期限、内容）
- [ ] 招标文件是否合规（资格条件、评标办法、实质性要求）
- [ ] 是否存在不合理条件限制、排斥潜在投标人
- [ ] 开标程序是否合规（公开开标、记录）
- [ ] 评标委员会组建是否合规（专家比例、回避）
- [ ] 评标办法是否执行到位

### 三、评标与定标
- [ ] 评标是否独立、公正
- [ ] 是否存在围标、串标迹象（投标文件雷同、报价规律等）
- [ ] 定标程序是否合规（按评标结果确定中标人）
- [ ] 中标结果是否依法公示

### 四、合同签订与履行
- [ ] 是否在规定期限内签订合同
- [ ] 合同实质性条款是否与招标文件、投标文件一致（不得改变实质性内容）
- [ ] 合同履行是否按约执行
- [ ] 验收与付款是否合规

### 五、国企特别关注
- [ ] 是否通过阳光采购平台/电子招投标系统
- [ ] 采购计划是否履行"三重一大"程序（重大采购）
- [ ] 采购预算是否落实
- [ ] 采购档案是否完整留存
- [ ] 供应商管理（黑名单、准入）是否落实

## 工作流程

### Step 1: 收集采购信息
请用户提供：
1. 采购项目名称、预算金额
2. 项目性质（工程/货物/服务）
3. 已选择的采购方式及理由
4. 采购程序文件（招标公告、招标文件、开标评标记录、中标通知）
5. 企业采购管理制度

### Step 2: 合规审查
按上述要点逐项审查，判定：合规 / 程序瑕疵 / 存在违规风险

### Step 3: 输出审查意见

```markdown
# 招标采购合规审查意见

## 一、采购概况
- 项目名称：
- 预算金额：
- 采购方式：
- 采购阶段（计划/招标/评标/定标/履约）：

## 二、审查结果
| 审查环节 | 要求 | 实际 | 是否合规 | 说明 |
|---------|------|------|---------|------|
| 采购方式选择 | 依法确定 | ... | ... | ... |
| 招标公告 | 依法发布 | ... | ... | ... |
| 招标文件 | 合规无歧视 | ... | ... | ... |
| 开标评标 | 合规 | ... | ... | ... |
| 定标公示 | 合规 | ... | ... | ... |
| 合同签订 | 与招标一致 | ... | ... | ... |

## 三、风险提示
[规避招标、排斥投标人、围标串标迹象、程序缺失等]

## 四、审查结论
- 合规 / 基本合规（需补正）/ 存在违规风险（建议整改）

## 五、整改建议
[逐项给出整改措施]

审查人：
```

## 审查铁律

1. **必须招标的不能规避**：达到法定标准的工程建设项目必须招标，规避招标是违规追责重点
2. **资格条件不得歧视**：不得设置与项目无关的资格条件排斥潜在投标人
3. **实质一致**：合同实质性条款必须与招标投标文件一致，背离属于违规
4. **串标识别**：注意投标文件雷同、投标人关联等串标特征
5. **地方平台要求**：提示用户遵守当地国资阳光采购平台的操作要求

## 输出前闸门（强制）

## Word 输出规范（统一）

所有正式 Word 文件统一使用套件脚本 `scripts/md2docx_gbt.py` 生成（GB/T 9704-2012 公文格式）：

```bash
python3 scripts/md2docx_gbt.py input.md output.docx --type gongwen
```

- 先输出 Markdown 供确认，确认后转 Word
- 脚本支持标记：`#`标题、`##`节标题、`|`表格、`>>`右对齐落款、`-`列表
- 文件命名：`{文种/事项}_{日期}.docx`
