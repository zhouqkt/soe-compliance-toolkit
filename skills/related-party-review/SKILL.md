# 关联交易审查（related-party-review）

对国有企业关联交易进行识别、定性与合规审查，重点防范利用关联交易输送利益、侵占国有资产。

## 关联方界定

### 一、与国有出资人（含集团）相关的关联方
1. 出资人（国家出资企业）及其控制的企业
2. 出资人的董事、监事、高级管理人员及其近亲属控制的企业

### 二、与企业自身相关的关联方
1. 企业的主要投资者（直接或间接控制企业的人）及其近亲属
2. 企业董事、监事、高级管理人员及其近亲属
3. 上述人员直接或间接控制的企业
4. 企业关键岗位人员（如财务负责人）及其关联人
5. 与企业存在受同一控制、共同控制或重大影响关系的企业

### 三、其他关联关系
- 通过股权穿透、人员交叉任职识别的其他关联关系
- 历史上存在关联、现已解除但仍有交易往来的特殊情形

## 关联交易认定

以下交易若发生在企业与关联方之间，构成关联交易：

| 类型 | 内容 |
|------|------|
| 采购类 | 采购商品、接受劳务、委托加工 |
| 销售类 | 销售商品、提供劳务 |
| 资金类 | 资金拆借、贷款担保、委托贷款 |
| 资产类 | 资产转让、资产收购、租赁 |
| 投资类 | 共同投资、增资、股权转让 |
| 服务类 | 咨询服务、技术服务、关联劳务 |
| 其他 | 捐赠、许可使用等 |

## 管控要求

### 事前
- [ ] 关联方清单是否建立并动态更新
- [ ] 交易前是否进行关联交易认定
- [ ] 是否履行回避制度（关联董事、关联股东回避表决）
- [ ] 是否按规定履行决策程序（董事会/股东会审批）

### 事中
- [ ] 交易价格是否公允（市场比较法/成本加成法等）
- [ ] 是否遵循商业实质（交易是否必要、合理）
- [ ] 是否按规定披露

### 事后
- [ ] 是否定期核查关联交易执行情况
- [ ] 是否存在关联交易额度聚合管理（合并口径授信/限额）
- [ ] 异常关联交易是否及时报告

## 风险识别清单

| 风险特征 | 识别信号 |
|---------|---------|
| 利益输送嫌疑 | 交易价格明显偏离市场公允价；先交易后补程序 |
| 虚增收入 | 通过关联方循环交易做大营收规模 |
| 资金占用 | 关联方长期占用资金；应收账款异常挂账 |
| 违规担保 | 未经决策为关联方提供担保 |
| 规避审批 | 化整为零拆分关联交易；隐藏关联关系 |
| 影子关联 | 通过多层股权、代持、人员交叉隐藏关联 |

## 工作流程

### Step 1: 收集信息
请用户提供：
1. 交易双方及交易内容
2. 双方股权结构、人员任职情况（用于关联方识别）
3. 交易金额、定价依据
4. 已履行的决策程序
5. 企业关联方清单（如有）

### Step 2: 关联方识别
基于股权、人员、控制关系判断是否构成关联关系。未接入工商信息能力时，标注待验证并提示用户通过企查查/天眼查核验。

### Step 3: 交易定性与程序审查
1. 是否构成关联交易
2. 决策程序是否合规（回避、审批层级）
3. 定价是否公允
4. 是否需披露

### Step 4: 输出审查意见

```markdown
# 关联交易合规审查意见

## 一、交易概况
- 交易双方：
- 关联关系认定：[关联方/非关联方/待验证]
- 关联关系依据：[股权/人员/控制关系]
- 交易内容及金额：
- 定价方式及公允性：

## 二、程序审查
| 审查环节 | 要求 | 实际 | 是否合规 | 说明 |
|---------|------|------|---------|------|
| 关联认定 | 事前认定 | ... | ... | ... |
| 回避表决 | 关联方回避 | ... | ... | ... |
| 决策程序 | 按规定层级审批 | ... | ... | ... |
| 披露 | 按规定披露 | ... | ... | ... |

## 三、风险识别
[列明识别的风险特征及依据]

## 四、审查结论
- 合规 / 基本合规（需补正）/ 存在利益输送风险（建议专项核查）

## 五、建议
[补正措施、额度管控、建立关联方清单等]

审查人：
日期：
```

## 审查铁律

1. **穿透识别**：关联关系识别须穿透多层股权和人员交叉，不能只看表面
2. **价格公允是核心**：关联交易最大风险是定价不公允，审查重点核对定价依据
3. **回避是硬要求**：关联方参与决策必须回避，未回避的决策程序有瑕疵
4. **额度聚合**：同一关联方体系内的交易应合并管控，防止拆分规避
5. **国企特殊性**：国有企业关联交易同时受国资监管约束，涉及国有资产交易的联动 32号令审查
