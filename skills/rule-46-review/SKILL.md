# 合规管理体系审查（rule-46-review）

依据《中央企业合规管理办法》（国资委令第46号）对国有企业合规管理体系建设与运行情况开展逐条对照审查，输出体检报告。

## 法规背景

《中央企业合规管理办法》（国资委令第46号，自2022年10月1日起施行）是当前中央企业及地方国有企业合规管理体系建设的基本遵循。审查以该办法为核心依据，结合国资委关于合规管理的最新要求开展。

## 审查范围（八大维度）

### 一、总则与合规管理定义（第1-4条）
- [ ] 企业是否明确合规、合规风险、合规管理的基本定义
- [ ] 合规管理是否遵循"坚持党的领导、全面覆盖、权责清晰、务实高效"原则
- [ ] 合规管理是否覆盖决策、执行、监督全流程及全体人员

### 二、组织与职责（第5-13条）
- [ ] 党委（党组）是否发挥把方向、管大局、促落实的领导作用
- [ ] 董事会是否履行合规管理顶层职责（审议基本制度、批准年度报告等）
- [ ] 经理层是否履行合规管理实施职责（拟订制度、制定流程等）
- [ ] 是否明确合规委员会或首席合规官
- [ ] 是否设置合规管理部门（牵头部门）
- [ ] 业务及职能部门、子企业合规职责是否明确

### 三、制度建设（第14-18条）
- [ ] 是否制定合规管理基本制度
- [ ] 是否制定重点领域专项合规管理制度（市场交易、合同管理、投融资、财务税收、安全环保、劳动用工、知识产权、数据合规、反垄断等）
- [ ] 制度是否覆盖境外业务领域
- [ ] 制度修订机制是否健全（根据法律法规变化及时更新）

### 四、运行机制（第19-28条）
- [ ] 合规风险识别评估机制是否建立（建议每年至少一次全面评估）
- [ ] 重大决策事项合规审查机制是否建立并嵌入决策流程
- [ ] 合规风险预警与应对机制是否建立
- [ ] 违规问题整改闭环机制是否落实
- [ ] 合规举报机制是否建立（受理、调查、处理、反馈）
- [ ] 协同监督机制（纪检监察、审计、法律合规）是否建立

### 五、合规文化（第29-32条）
- [ ] 合规文化理念是否宣贯（领导层带头）
- [ ] 合规培训是否纳入员工教育培训体系
- [ ] 合规承诺制度是否建立（重要岗位签署合规承诺书）

### 六、信息化建设（第33-34条）
- [ ] 合规管理信息系统是否建设
- [ ] 合规风险数据是否实现动态监测

### 七、监督问责（第35-38条）
- [ ] 合规管理纳入考核评价体系
- [ ] 违规责任追究机制是否落实
- [ ] 合规报告制度是否执行（年度合规管理报告）

### 八、保障措施
- [ ] 合规管理人员配备是否到位
- [ ] 合规管理经费保障是否落实

## 工作流程

### Step 1: 收集企业合规管理材料
请用户提供（按实际情况）：
1. 企业《合规管理办法》或合规管理制度文件
2. 合规管理组织架构图（或职责文件）
3. 重点领域专项合规制度清单
4. 上年度合规管理报告
5. 合规培训、合规审查记录等佐证材料

### Step 2: 逐条对照审查
按上述八大维度逐项检查，每项给出判定：
- **合规**：制度健全且有效执行
- **部分合规**：有制度但执行不到位/有缺口
- **不合规**：无制度或无机制
- **不适用**：企业不涉及该情形

每项判定附：对照依据（46号令具体条款）、事实依据（用户提供的材料）、差距说明。

### Step 3: 输出体检报告

```markdown
# 合规管理体系体检报告（46号令对照）

## 一、企业基本信息
- 企业名称：
- 企业性质（央企/地方国企/金融国企）：
- 所属层级：
- 业务板块：
- 审查日期：

## 二、总体评价
- 综合得分：XX/100
- 合规项：X项 / 部分合规：X项 / 不合规：X项 / 不适用：X项
- 总体结论：[体系健全/基本健全/存在明显短板/体系缺失]

## 三、逐项审查结果
| 维度 | 审查项 | 判定 | 依据 | 差距说明 | 整改建议 |
|------|--------|------|------|---------|---------|
| ... | ... | ... | 46号令第X条 | ... | ... |

## 四、重点问题清单
[按严重程度排序，列出不合规/部分合规项及整改优先级]

## 五、整改建议
[分短期（1个月内）、中期（3个月内）、长期（6个月以上）给出整改路径]

## 六、依据文件
- 《中央企业合规管理办法》（国资委令第46号）
- 其他相关监管文件

审查人：
日期：
```

### Step 4: 整改跟踪建议
- 对"不合规"项建议建立整改台账
- 对"部分合规"项建议明确责任部门和完成时限
- 建议半年至一年后复检

## 审查铁律

1. **以现行有效法规为准**：46号令条款引用须核验；不确定时标注待核验
2. **不臆造企业情况**：企业未提供的材料不假设存在，标注"待补充"
3. **区分制度与执行**：有制度不代表合规，须同时审查执行证据
4. **地方国企差异**：地方国资委可能有更具体要求（如《地方国有企业合规管理指引》），提示用户结合所在地区规定
5. **输出为辅助意见**：最终以企业合规管理部门认定为准

## Word 输出规范（统一）

所有正式 Word 文件统一使用套件脚本 `scripts/md2docx_gbt.py` 生成（GB/T 9704-2012 公文格式）：

```bash
python3 scripts/md2docx_gbt.py input.md output.docx --type gongwen
```

- 先输出 Markdown 供确认，确认后转 Word
- 脚本支持标记：`#`标题、`##`节标题、`|`表格、`>>`右对齐落款、`-`列表
- 文件命名：`{文种/事项}_{日期}.docx`
