# 贸易真实性核验（trade-authenticity-check）

对国有企业贸易业务（尤其是供应链贸易、大宗商品贸易）开展贸易背景真实性核查，重点防范融资性贸易、空转贸易、循环贸易等国资监管明令禁止的违规贸易行为。

## 监管背景与红线

根据国务院国资委关于严禁融资性贸易和空转贸易的相关要求，国有企业不得开展以下行为：

1. **融资性贸易**：以贸易为名、实为出借资金、无商业实质的贸易
2. **空转贸易**：无真实货物流转、仅流转单据和资金、循环开票的贸易
3. **循环贸易**：同一批货物在关联闭环内反复交易、虚增交易规模
4. **"走单、走票、不走货"**：仅有合同、发票流转，无实际货物流转

## 核验框架：四流合一

| 四流 | 核查内容 | 证据材料 | 风险特征 |
|------|---------|---------|---------|
| 合同流 | 采购合同与销售合同对应关系 | 采购合同、销售合同、框架协议 | 上下游合同条款高度雷同；数量价格倒挂；合同签订时间异常 |
| 货物流 | 货物是否真实存在并发生转移 | 入库单、出库单、过磅单、仓单、运单、签收单 | 无物流单据；货权转移不清；仓单重复质押；同一货物反复交易 |
| 资金流 | 资金往来是否真实对应贸易 | 付款凭证、收款凭证、银行回单 | 资金在关联方闭环流转；付款与回款时间间隔异常短；预付比例异常 |
| 发票流 | 发票与合同、货物、资金是否匹配 | 增值税发票、进项/销项台账 | 发票金额与合同不符；发票开具时间异常；同一发票重复融资 |

## 核验工作流

### Step 1: 收集贸易材料清单

要求用户提供（按优先级）：

1. 采购合同 + 销售合同（含合同编号、签订日期、标的、数量、单价、交货方式、结算方式）
2. 物流单据：运单、仓单、出入库单、过磅记录、签收单
3. 资金凭证：付款申请、银行回单、收款确认
4. 发票台账：进项发票、销项发票
5. 贸易背景材料：上下游客户信息、询价记录、仓储协议

### Step 2: 逐流核验

按"四流合一"框架逐项比对：

- **合同流**：购销合同是否一一对应（同一标的、数量匹配、价格合理）
- **货物流**：货权转移链条是否完整（供应商→我方→客户）；仓储是否真实（仓单核验、仓储企业资质）
- **资金流**：先收款后付款原则是否执行；资金是否闭环；预付比例与货权比例是否匹配
- **发票流**：发票抬头、金额、品名是否与合同一致；发票真伪可查验

### Step 3: 风险特征识别

逐项检查以下高风险特征：

| 风险特征 | 识别信号 |
|---------|---------|
| 融资性贸易嫌疑 | 上下游为同一实际控制人或关联方；贸易无真实货物需求；购销差价极低或倒挂 |
| 空转贸易嫌疑 | 无实物交割，仅有单据流转；合同、发票、资金循环 |
| 循环贸易嫌疑 | 同一批货物短期内反复交易；买卖双方在闭环内 |
| 虚假仓单 | 仓单格式不规范；仓储企业资质存疑；仓单与库存记录不一致 |
| 关联方构造贸易 | 买卖双方股权、人员存在关联；贸易目的不明 |
| 客户集中度过高 | 单一客户占比过高（监管关注阈值：客户集中度>40%） |
| 付款异常 | 先付款后收款；付款与回款时间间隔过短；无客户订单即向供应商付款 |

### Step 4: 输出核查意见

按"绿/黄/红"三级出具贸易真实性核查意见：

- **绿色（正常）**：四流一致，无异常特征
- **黄色（存疑）**：存在部分异常特征，需补充材料或人工复核
- **红色（高风险）**：存在融资性贸易/空转贸易/循环贸易特征，建议立即停止业务并启动专项调查

## 审查要点（铁律）

1. **先收款后付款**：无客户订单和收款记录，不得向供应商付款——这是贸易合规的核心底线
2. **货权必须真实**：无法证明货物真实存在和货权转移的，一律标为风险事项
3. **不臆造证据**：用户未提供的材料不得假设存在，缺失项明确列出
4. **关联方穿透**：核查买卖双方股权、人员关联，识别关联方构造贸易
5. **数据标注**：基于推理的判断标注"待验证"，基于用户提供材料的事实标注来源

## Word 输出规范（统一）

所有正式 Word 文件统一使用套件脚本 `scripts/md2docx_gbt.py` 生成（GB/T 9704-2012 公文格式）：

```bash
python3 scripts/md2docx_gbt.py input.md output.docx --type gongwen
```

- 先输出 Markdown 供确认，确认后转 Word
- 脚本支持标记：`#`标题、`##`节标题、`|`表格、`>>`右对齐落款、`-`列表
- 文件命名：`{文种/事项}_{日期}.docx`
