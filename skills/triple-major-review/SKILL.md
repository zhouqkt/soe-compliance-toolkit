# "三重一大"决策审查（triple-major-review）

对国有企业"三重一大"事项进行识别判定，并审查决策程序的合规性。

## 制度背景

"三重一大"制度是指重大决策、重要人事任免、重大项目安排、大额度资金运作（简称"三重一大"）必须经集体讨论作出决定的制度，是国有企业坚持民主集中制、防止独断专行的重要制度安排。主要依据：

- 中共中央办公厅、国务院办公厅《关于进一步推进国有企业贯彻落实"三重一大"决策制度的意见》（中办发〔2010〕17号）
- 企业章程及"三重一大"决策制度实施办法

## 事项识别标准

### 一、重大决策事项
一般包括：
- 企业发展战略、中长期发展规划的制定和调整
- 企业年度生产经营计划、投资计划
- 企业改制、兼并、重组、破产等重大事项
- 产权转让、对外投资、大额捐赠
- 重要规章制度的制定和修改
- 涉及职工切身利益的重大事项

### 二、重要人事任免事项
一般包括：
- 企业中层以上经营管理人员的任免、奖惩
- 重要岗位人员的调整
- 向控股、参股企业委派或更换高级管理人员

### 三、重大项目安排事项
一般包括：
- 重大工程建设项目
- 重大技术改造、技术引进项目
- 重大对外合作项目
- 重大资产处置项目

### 四、大额度资金运作事项
一般包括：
- 大额资金调度使用
- 大额采购、大额担保
- 大额对外融资、投资
- 大额资产处置

> 具体金额标准由企业根据规模、行业特点自行确定，报上级备案。审查时以企业"三重一大"制度规定的金额阈值为准。

## 决策程序审查要点

### 前置程序
- [ ] 是否进行充分调查研究
- [ ] 是否经过专家论证、风险评估（重大项目）
- [ ] 是否征求相关部门意见
- [ ] 是否履行法律合规审查

### 决策程序
- [ ] 是否由党委（党组）前置研究讨论（重大经营管理事项）
- [ ] 是否经董事会/总经理办公会集体讨论决定
- [ ] 是否遵守"先论证、后决策"程序
- [ ] 参会人数、表决程序是否符合规定
- [ ] 是否存在"一言堂"、先斩后奏情形
- [ ] 紧急事项是否履行了相应程序（事后补报）

### 执行与监督
- [ ] 决策事项是否明确责任部门和责任人
- [ ] 是否建立决策执行跟踪与后评估机制
- [ ] 决策执行情况是否纳入监督
- [ ] 重大失误是否追究责任

## 工作流程

### Step 1: 事项定性
请用户提供事项描述，判断属于"三重一大"哪类（可能多类叠加），并对照企业制度阈值判定是否达到标准。

### Step 2: 程序审查
按上述决策程序审查要点逐项检查，重点核实：
1. 是否走了前置程序（调研、论证、合规审查）
2. 决策主体是否正确（该党委会前置的有没有前置，该董事会上会的有没有上会）
3. 表决程序是否合规（集体讨论、按表决规则）
4. 有无程序缺失或倒置

### Step 3: 输出审查意见

```markdown
# "三重一大"决策合规审查意见

## 一、事项概况

- 拟决策金额/规模：
- 决策主体（拟）：党委会 / 董事会 / 总经理办公会

## 二、定性结论
- 是否属于"三重一大"事项：是 / 否
- 依据：企业制度第X条；金额阈值标准

## 三、程序审查结果
```

## 审查铁律

1. **标准以企业制度为准**：金额阈值、事项范围以企业"三重一大"制度及上级要求为准，提示用户提供制度文件
2. **党委前置是重点**：重大经营管理事项须经党委（党组）前置研究讨论，这是当前国企治理的刚性要求
3. **不替代决策**：本技能仅审查程序合规，不评价决策内容好坏
4. **紧急事项特殊处理**：遇紧急情况确需简化程序的，须事后按程序确认并留痕

## Word 输出规范（统一）

所有正式 Word 文件统一使用套件脚本 `scripts/md2docx_gbt.py` 生成（GB/T 9704-2012 公文格式）：

```bash
python3 scripts/md2docx_gbt.py input.md output.docx --type gongwen
```

- 先输出 Markdown 供确认，确认后转 Word
- 脚本支持标记：`#`标题、`##`节标题、`|`表格、`>>`右对齐落款、`-`列表
- 文件命名：`{文种/事项}_{日期}.docx`
